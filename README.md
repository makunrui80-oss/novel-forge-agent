# 小说智能体

本地运行的小说拆解与写作 Web 应用，支持参考书拆解、原创大纲、正文写作、模型配置、成本统计和中文内容检测。

## 启动

双击 `启动.command`（macOS）、`启动.bat`（Windows）或 `启动.sh`（Linux），首次启动会自动创建 `.venv`、安装依赖、后台运行服务并打开浏览器。三套入口都调用同一个 `启动.py`，可在本机部署，不需要 Docker。

需要先安装 Python 3.10 或更高版本，首次安装依赖需要联网。启动文件须保留在项目文件夹中；Mac 桌面快捷入口请制作替身。项目文件夹可以改名，启动路径会按文件所在目录计算。

启动器只复用同目录的本程序。发现代码已更新时，会重启空闲服务以加载新版本；有任务运行时先保留任务，完成后再次双击启动即可加载更新。终端窗口关闭后后台服务仍继续运行。

首次打开后到「设置」填写你自己的模型 API Key。`config.json`、`data/` 和日志只保存在本机，发布代码时不会提交。

朱雀分数是检测服务返回的“疑似 AI 内容占比”，100 分表示接口返回了 1.0，程序不会伪造或压低这个分数。超标时会进行有限次数的自然编辑，重点改善句式、对白、段落节奏和具体动作；检测器不是作者判定工具，任何系统都不能保证固定分数或绕过第三方检测。

每章新写、重写、优化及自动编辑都读取原创大纲、本章计划和前五章正文。候选稿先检查核心事件与事实承接，再替换；新写发现实质偏离时自动修复一次。模型检查也可能判断失误，未通过的候选稿与原因会暂存，不覆盖正式正文。增加的剧情检查会产生一次额外模型调用。

自动编辑还须重新检测：只有分数改善才替换，持平或升高时保留较低分稿。正文修改后清除旧分数，历史检测保存正文指纹与接口判定字段，阅读窗口会提示检测是否对应当前版本。检测失败保留正文，不伪造合格结果。

## 数据

项目数据保存在 `data/`，配置在 `config.json`。请定期备份 `data/` 目录。
