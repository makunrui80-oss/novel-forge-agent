# 小说智能体

跨平台本地小说拆解与写作 Web 应用，支持参考书拆解、原创大纲、分章写作与润色、模型 API 配置、费用统计及朱雀文本检测。

## Windows、macOS、Linux 本地部署

需要 Python 3.10+ 与首次安装所需的网络连接。下载或克隆仓库后，在项目目录启动：

- Windows：双击 `启动.bat`
- macOS：双击 `启动.command`（如被拦截，在 Finder 右键选择「打开」）
- Linux：运行 `./启动.sh`

也可在任一系统运行 `python 启动.py`。首次启动自动创建 `.venv` 并安装依赖，然后打开本地网页；不需要 Docker。若 Linux 文件没有执行权限，运行 `chmod +x 启动.sh`。启动器绑定本机地址；同一网络中的其他设备默认无法访问。

## 首次配置

在网页左侧打开「08 设置」，添加你自己的模型供应商，填写服务商 API 地址、Key 和模型名称，测试并保存；然后为分析、大纲、写作、检查、润色各阶段选择模型。兼容服务和 Anthropic 的字段说明见 [模型 API 与朱雀配置](docs/API_SETUP.md)。

朱雀检测需要用户自行申请和配置服务 Key。官方 Makers 或自定义接口均可在设置中配置；没有 API 时可使用页面提供的手动检测流程。检测会把正文发送给用户选择的第三方服务商，请先确认其隐私政策、授权与费用。

## 功能

可导入参考小说并分批拆解，基于拆解结果与新书要求生成原创大纲和章节计划，再逐章写作、续写、重写或润色。项目、章节、任务和费用统计保存在本地。更多界面功能说明见 [功能说明](docs/FEATURES.md)，图文操作步骤见 [中文使用说明](使用说明.txt)。

## 配置和数据安全

`config.json` 保存本机 API Key 等设置，`data/` 保存本机数据库；两者均被 Git 忽略。请勿提交配置、数据库、个人小说或日志。发布源码不会替下载者配置密钥；每位使用者都必须在自己的电脑申请并输入自己的 Key，费用按相应服务商政策结算。请仅在可信设备上使用，并定期备份 `data/`。

## 开发与验证

```sh
python -m pip install -r requirements.txt
python -m unittest discover -s tests -q
node --check static/app.js
```

GitHub Actions 会在 Ubuntu、Windows 和 macOS 上执行启动相关测试。测试不需要真实模型 Key。
