# 功能说明

本程序在本机浏览器中运行，提供以下工作区：

- 参考书拆解：导入文本、识别章节、分批生成章节摘要与全书档案。
- 原创大纲：基于创作要求生成或完善大纲和章节计划。
- 正文写作：按章写作、续写、重写和润色，保留章节与前文上下文。
- 朱雀检测：调用已配置的检测接口，查看结果；也可复制正文到网页检测后手动录入。
- 项目数据：保存项目、章节和任务状态，并统计模型 token 与配置的费用。
- 任务中心：查看任务状态、错误信息，并按界面提供的操作继续或取消任务。

实际可用功能取决于模型供应商接口、模型能力、朱雀账号权限和本机环境。服务默认仅绑定回环地址，供本机访问，不应直接暴露到公网。
