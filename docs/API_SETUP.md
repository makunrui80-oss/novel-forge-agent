# 模型 API 与朱雀配置

## 模型 API

首次启动后，打开左侧「08 设置」：

1. 选择「添加供应商」。
2. 常用的 DeepSeek、通义千问、Kimi、豆包及兼容中转服务选择「OpenAI 兼容」；Anthropic 官方或兼容服务选择「Anthropic」。
3. 填写服务商提供的 API Base URL、API Key 和模型名。不要把 Key 发给他人，也不要写进源码。
4. 点击「测试接通」并保存。
5. 在「分环节模型」为拆书分析、大纲、正文写作、检查和润色选择可用模型，然后保存设置。

也可以复制 `config.example.json` 为 `config.json` 后编辑。把示例供应商 URL、名称、模型名替换成你的服务商实际值，并将 Key 放到本地配置中。`config.json` 已加入 Git 忽略规则；请勿强行添加或提交它。应用保存设置时会在支持的平台上尽量限制本地配置文件权限。

`base_url` 应按服务商文档填写 API 根路径（通常以 `/v1` 结尾）；程序会自动补上聊天补全或 Anthropic Messages 路径。不同服务商的模型名称和兼容能力不同，请以服务商文档为准。

## 朱雀接口

在设置页的「朱雀检测」中配置：

- 官方腾讯云 Makers：选择 Makers 适配器，粘贴自己的 Makers Models API Key。该模式使用程序内置的官方检测地址，不需要复制他人的网关密钥。
- 自建或其他兼容接口：选择通用适配器，填写 endpoint、HTTP 方法、API Key、请求头、请求体模板与分值 JSON 路径。请保留程序识别的 `{{text}}` 模板占位符。
- 可设置超时、检测阈值、自动压缩目标分和轮数。API 余额/积分字段由供应商响应决定；只有接口实际返回该信息时才会显示。
- 不希望自动请求时，关闭 API 自动检测，使用章节窗口中的复制正文和手动记录结果功能。

使用朱雀前先确认你的服务账号权限、套餐和服务条款。检测分数是第三方接口返回的评估，不是作者身份判定，也不保证特定结果。正文会在检测时发送给你配置的第三方服务商。

## 安全与隐私

- 每位使用者都应在自己的设备上输入自己的 API Key。项目不提供共享密钥，也没有能替下载者自动生成或代配密钥的方式；API 访问需要用户自行向服务商申请并承担其费用与条款。
- API Key 保存在本地 `config.json`。不要截图、上传、提交或发送该文件。
- 小说数据库与其他本地数据保存在 `data/`。不要将个人小说、参考书、创作记录或日志提交到公开仓库。
- 清理 Git 历史中的文件并不能撤销已泄露的密钥；如误提交，立即在服务商控制台吊销并重新生成。
